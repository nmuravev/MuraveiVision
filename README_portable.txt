ЗАПУСК
─────
  Дважды кликните на MuraveiVision.exe.
  Приложение откроется сразу — без окна выбора.

  Для проверки сборки без GUI:
    MuraveiVision.exe --selftest
    Должно напечатать "✅ SELFTEST OK".


МОДЕЛИ
──────
  ONNX-модели лежат в папке models/ рядом с exe.
  По умолчанию в сборку копируются все *.onnx из models/ исходного проекта.

  Добавить новую модель:
    1) В GUI: кнопка "➕ Добавить модель" → выберите .onnx файл.
       Модель скопируется в models/ и станет активной.
    2) Вручную: скопируйте .onnx в models/, перезапустите приложение.

  Выбор модели:
    - В GUI: выпадающий список "🤖 Модель" в панели настроек.
    - Через .env: MODEL_OVERRIDE=<имя_файла.onnx>
      (если файл существует — он выбран при старте, иначе авто-выбор)


ОБЛАЧНЫЙ СЛОЙ (NVIDIA Vision)
─────────────────────────────
  Облачная обработка данных (слой 4) доступна только при наличии:
    1) API-ключа NVIDIA (NVIDIA_API_KEY в .env);
    2) Внешнего прокси (NVIDIA_PROXY в .env) — политика безопасности.

  Без прокси облако отключено (работают только локальные слои 1-3).

  Настройка:
    1) Скопируйте .env.example в .env (рядом с exe).
    2) Заполните NVIDIA_API_KEY и NVIDIA_PROXY.
    3) Перезапустите приложение.


HTML-ОТЧЁТЫ
───────────
  После анализа создаётся HTML-отчёт в папке output/.
  Отчёт самодостаточный (все миниатюры встроены как base64),
  открывается в любом браузере.

  Кнопки в GUI:
    📂 Открыть отчёт — загрузить JSON-отчёт из output/
    📄 Открыть HTML — открыть последний HTML-отчёт в браузере

  В HTML-отчёте:
    - поиск по классу, сортировка (время/confidence);
    - чекбоксы выбора карточек;
    - "💾 Сохранить выбранные" — ZIP с миниатюрами + gallery.html;
    - "📋 Скачать JSON" — выгрузка JSON-отчёта.


СТРУКТУРА ПОРТАТИВНОЙ СБОРКИ
───────────────────────────
  MuraveiVision/
    ├── MuraveiVision.exe      — запуск
    ├── models/                — ONNX-модели
    ├── output/                — отчёты (HTML, JSON, стоп-кадры)
    ├── .env.example           — шаблон настроек
    ├── .env                   — ваши настройки (создаётся из .env.example)
    └── README_portable.txt    — этот файл


ПРОВЕРКА СБОРКИ
───────────────
  MuraveiVision.exe --selftest

  Ожидаемый вывод:
    🧪 MuraveiVision Self-Test
    1. Импорт модулей...        ✅
    2. Определение железа...    ✅
    3. Доступные модели...      📦 (список)
    4. Загрузка модели YOLO...  ✅
    ✅ SELFTEST OK

  Если selftest падает — проверьте:
    1) models/ содержит хотя бы один .onnx;
    2) onnxruntime совместим с вашей ОС/архитектурой;
    3) .env не содержит ошибок.
